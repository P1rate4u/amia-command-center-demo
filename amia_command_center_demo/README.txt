AMIA COMMAND CENTER — INTERACTIVE DEMO

This is a standalone browser demo for Louis and the Amia team.
It contains dummy/illustrative data only and does not connect to live Amia systems.

HOW TO RUN
1. Open index.html in Chrome, Edge, Safari, or Firefox.
2. No installation, server, login, or internet connection is required.

WHAT TO TRY
- Use the left sidebar to move between Dashboard, Investor Outreach, MedNova Operations, Tasks, Documents, Automation, Reports, and Customers.
- Check a task to mark it complete.
- Change an investor status or click "Simulate reply".
- Mark a missing document as received.
- Advance a MedNova project stage.
- Create a new demo project/task/investor from the + button.
- Run the Demo Health Check.
- Search with the top search box or Ctrl/Cmd + K.
- Changes are stored in browser local storage until "Reset demo data" is clicked.

IMPORTANT
This is a clickable prototype to demonstrate the intended experience. It is not connected to Google Sheets, AppSheet, Zapier, Slack, Apollo, MedNova, customer data, or real investor data.
